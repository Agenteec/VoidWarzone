# Fonts

- `Roboto-Bold.ttf` — Roboto by Christian Robertson, Apache License 2.0 (copied from the bgfx examples runtime).
- Roboto Regular and Font Awesome 4 (SIL OFL 1.1) are embedded in the client from `bgfx/examples/common/imgui`.
- `NotoEmoji-Regular.ttf` — Noto Emoji (monochrome) by Google, SIL Open Font License 1.1 (`OFL-NotoEmoji.txt`), merged into the UI fonts for emoji in chat and names.
